# StudyMate AI

## Problem Statement

Students often waste hours manually creating flashcards, condensing massive textbooks, and organizing messy lecture notes before exams. This repetitive work takes valuable time away from actual learning and understanding, leading to inefficient study habits and lower retention.

## Solution

StudyMate AI is a full-stack MERN application that uses Google Gemini AI to automatically transform study materials into powerful learning tools. Students can upload PDFs, TXT files, or paste lecture notes to instantly generate:

- AI-powered summaries
- Active-recall flashcards
- Practice quizzes with explanations
- Performance analytics
- Weak topic detection
- Personalized revision recommendations

## Features

### Core Features
- **Multi-format Upload**: Support for PDF, TXT files, and direct text input
- **AI Summaries**: Concise, exam-focused summaries generated by Gemini
- **Smart Flashcards**: Active-recall flashcards with difficulty levels and topic categorization
- **Practice Quizzes**: MCQ quizzes with explanations and instant feedback
- **Progress Analytics**: Visual charts showing subject-wise performance
- **Weak Topic Detection**: Identifies areas needing more practice
- **AI Revision Recommendations**: Personalized study suggestions based on performance

### User Features
- User authentication (Register, Login, Logout)
- Protected routes and JWT authorization
- Personal dashboard with statistics
- Material management (view, delete, search, filter)
- Profile management
- Responsive design for all devices

## Architecture

### Database Models

#### User
- name (String)
- email (String, unique)
- password (String, hashed)
- createdAt (Date)

#### StudyMaterial
- user (ObjectId, ref: User)
- title (String)
- subject (String)
- type (String: pdf/txt/notes)
- originalText (String)
- summary (String)
- fileName (String)
- createdAt (Date)
- updatedAt (Date)

#### Flashcard
- user (ObjectId, ref: User)
- material (ObjectId, ref: StudyMaterial)
- question (String)
- answer (String)
- topic (String)
- difficulty (String: Easy/Medium/Hard)
- createdAt (Date)

#### Quiz
- user (ObjectId, ref: User)
- material (ObjectId, ref: StudyMaterial)
- title (String)
- difficulty (String: Easy/Medium/Hard)
- questions (Array of Question objects)
- createdAt (Date)

#### QuizAttempt
- user (ObjectId, ref: User)
- quiz (ObjectId, ref: Quiz)
- score (Number)
- percentage (Number)
- answers (Array of answer objects)
- timeTaken (Number)
- attemptedAt (Date)

## API Endpoints

### Authentication
- `POST /api/auth/register` - Register new user
- `POST /api/auth/login` - Login user
- `GET /api/auth/me` - Get current user (protected)

### Materials
- `POST /api/materials` - Create new material (protected)
- `GET /api/materials` - Get all user materials (protected)
- `GET /api/materials/:id` - Get specific material (protected)
- `DELETE /api/materials/:id` - Delete material (protected)
- `POST /api/materials/:id/summary` - Generate AI summary (protected)
- `POST /api/materials/:id/flashcards` - Generate AI flashcards (protected)
- `POST /api/materials/:id/quiz` - Generate AI quiz (protected)

### Flashcards
- `GET /api/flashcards` - Get all user flashcards (protected)
- `GET /api/flashcards/:id` - Get specific flashcard (protected)
- `GET /api/flashcards/material/:materialId` - Get flashcards by material (protected)
- `DELETE /api/flashcards/:id` - Delete flashcard (protected)

### Quizzes
- `GET /api/quizzes` - Get all user quizzes (protected)
- `GET /api/quizzes/:id` - Get specific quiz (protected)
- `POST /api/quizzes/:id/attempt` - Submit quiz attempt (protected)
- `GET /api/quizzes/attempts` - Get quiz attempts (protected)
- `GET /api/quizzes/attempts/:id` - Get specific attempt details (protected)

### Progress
- `GET /api/progress` - Get user progress statistics (protected)
- `GET /api/progress/subject-performance` - Get subject-wise performance (protected)
- `GET /api/progress/revision` - Get AI revision recommendations (protected)

### Profile
- `GET /api/profile` - Get user profile (protected)
- `PUT /api/profile` - Update user profile (protected)

## Gemini Integration

The application uses Google Gemini API for all AI functionality:

### AI Services
- **Summary Generation**: Creates concise, exam-focused summaries
- **Flashcard Generation**: Generates active-recall questions with answers
- **Quiz Generation**: Creates MCQ questions with explanations
- **Revision Explanations**: Provides quick revision content for weak topics

### Security
- All Gemini API calls are made from the backend
- API key is stored in environment variables
- No API keys are exposed to the frontend
- Structured JSON output with validation

## Environment Setup

### Prerequisites
- Node.js (v14 or higher)
- MongoDB (local installation or MongoDB Atlas)
- Google Gemini API Key

### Getting Google Gemini API Key
1. Go to [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Create a new API key
3. Copy the API key for use in environment variables

## Installation

### 1. Clone the Repository
```bash
git clone <repository-url>
cd StudyMate-AI
```

### 2. Backend Setup
```bash
cd backend
npm install
```

### 3. Frontend Setup
```bash
cd frontend
npm install
```

### 4. Environment Configuration

Create a `.env` file in the backend directory:

```env
PORT=5000
MONGO_URI=mongodb://localhost:27017/studymate
JWT_SECRET=your-secret-key-here
GEMINI_API_KEY=your-gemini-api-key-here
```

Create a `.env` file in the frontend directory:

```env
VITE_API_URL=http://localhost:5000/api
```

## Running the Application

### Start MongoDB
Make sure MongoDB is running on your system or use MongoDB Atlas connection string.

### Start Backend
```bash
cd backend
npm run dev
```

The backend will run on `http://localhost:5000`

### Start Frontend
```bash
cd frontend
npm run dev
```

The frontend will run on `http://localhost:3000`
